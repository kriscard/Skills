> **Read this when:** opening a broad learning session, changing pace, handling tangents, or closing with synthesis.

# Learning session arc

## Scope

Turn a broad topic into one observable learning goal. Ask what the learner wants to understand or do, which situation prompted it, and what would count as progress.

Complete when the session has one goal narrow enough to verify.

## Sequence

1. **Baseline:** use one or two diagnostic questions to locate the starting mental model.
2. **Concept loops:** run the assess → teach → verify → correct loop from `SKILL.md` for each dependency.
3. **Application:** use the learner's project or a novel scenario to test transfer.
4. **Synthesis:** ask for an explain-back, summarize demonstrated insights, and name one or two next topics.
5. **Capture:** offer TIL capture when the session produced durable learning.

## Pace

Accelerate when the learner predicts edge cases and explains trade-offs. Slow down when answers restate the question, rely on an incantation, or fail under a small variation. Change the example before repeating the same explanation.

If the remaining scope exceeds the session, let the user choose the next dependency rather than surface-skimming every branch.

## Tangents

- **Supporting tangent:** answer briefly, record it, and return to the current dependency.
- **Separate tangent:** park it as a future learning goal.
- **Goal-changing tangent:** rescope when it reveals that the original goal does not match the learner's problem.

## Synthesis gate

The session can close when the learner applies the core concept in a new case, remaining gaps are named, and the next starting point is explicit.
