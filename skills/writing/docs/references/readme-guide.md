> **Read this when:** creating or revising a README that must help a developer decide whether they can use a project quickly.

# README Guide

A README answers: "what is this, and can I use it in 2 minutes?"

## Rules

- First sentence: what this is now, not what it may become.
- Installation in fewer than 5 commands. If setup is longer, show the common path and link to full setup.
- One working example before conceptual explanation.
- Link to full docs instead of duplicating them.

## Structure

```markdown
# Project Name

One sentence description.

## Install

[<5 commands]

## Quick Start

[One working example]

## Documentation

[Links to deeper docs if needed]
```

## Completion Gate

The README is ready when a new developer can identify purpose, install, and run one useful example without leaving the doc except for linked prerequisites.
